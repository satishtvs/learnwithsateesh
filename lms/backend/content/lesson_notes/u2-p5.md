### Recap: RBF networks
- Part 4: radial basis function networks
- Hidden units respond to the distance from a centre
- Output is a weighted sum of these local responses
- A kernel is a similar idea to a radial basis function

### Which line is the best line?
- Many lines separate the same training data
- All have zero training error, but not equal quality
- Choose the line with the widest empty gap
- A wide gap is more robust to noise in new data

### Margin and support vectors
- Classifier: sign of w transpose x plus b, targets t = +1 or -1
- Margin: width of the empty strip around the line
- Support vectors lie on the edges of the strip
- Other points do not affect the line at all

### Margin geometry and the optimisation
- Distance of x from the line: |w transpose x + b| / length of w
- Scale w and b so support vectors have w transpose x + b = +1 or -1
- Margin = 2 / length of w, so a wide margin means a short w
- Minimise one half of the length of w squared
- Subject to t i times (w transpose x i + b) >= 1 for every i
- Convex quadratic problem: one global optimum

### The dual form and alpha i
- One Lagrange multiplier alpha i >= 0 for each training point
- w = sum over i of alpha i t i x i
- alpha i > 0 only for support vectors
- Also: sum of alpha i t i = 0
- Prediction: sign of sum of alpha i t i (x i . x) + b

### Worked example in code
- Class minus one: (1,1), (2,0), (1,3). Class plus one: (4,4), (5,3), (4,6)
- Support vectors: (1,3) and (4,4), alpha i = 0.2 each
- w = (0.6, 0.2), b = -2.2, margin = 3.16

```python
import numpy as np
from sklearn.svm import SVC
X = np.array([[1,1],[2,0],[1,3],[4,4],[5,3],[4,6]])
t = np.array([-1,-1,-1,1,1,1])
m = SVC(kernel="linear", C=1e6).fit(X, t)
print(m.support_vectors_)       # [[1. 3.] [4. 4.]]
print(m.coef_, m.intercept_)    # [[0.6 0.2]] [-2.2]
print(m.dual_coef_)             # [[-0.2  0.2]]
print(2 / np.linalg.norm(m.coef_))   # about 3.16
```

### Soft margin: allowing mistakes
- Real data overlaps; one noisy point can ruin a hard margin
- Slack variable xi i >= 0 lets point i enter the strip or cross the line
- Minimise half of length of w squared + C times sum of xi i
- Constraint becomes t i (w transpose x i + b) >= 1 - xi i

### The parameter C: a real experiment
- Small C: wide margin, many support vectors, tolerant
- Large C: narrow margin, punishes every violation
- C 0.01: 57 SVs, width 3.83. C 100: 17 SVs, width 1.17

### The kernel trick: lift the data
- Circle data: no straight line separates inner from outer
- Add a feature z = x1 squared + x2 squared
- Inner class: z at most 0.95. Outer class: z at least 4.25

### Kernel functions
- K(x, z) = phi(x) . phi(z): an inner product in a feature space
- Linear: K = x . z
- Polynomial: K = (1 + x . z) to the power d
- Gaussian (RBF): K = exp(-gamma times length of (x - z) squared)
- Never compute phi: just evaluate K

### RBF-kernel decision regions
- Two-moons data, 120 training points, noise added
- gamma 1: 44 SVs, test accuracy 0.925
- gamma 100: 115 SVs, train 0.975 but test 0.873
- Large gamma: tiny bumps around each point, overfits

### Choosing a kernel and parameters
- Start with linear if features are many; try RBF otherwise
- Scale the inputs first: kernels depend on distances
- Tune C and gamma by cross validation on a grid
- Polynomial: tune degree d. Too high overfits

### Multi-class and regression
- An SVM is binary: two classes
- One-versus-rest: K classifiers, pick the largest output
- One-versus-one: K(K-1)/2 classifiers, majority vote
- Regression (SVR): fit a tube of width epsilon, ignore errors inside it

### SVM versus MLP
- SVM: convex problem, global optimum; MLP: local minima
- SVM: few parameters to tune (C, kernel); MLP: layers, units, rate
- SVM: slow for very large data; MLP: scales with mini-batches
- SVM: no learned features; MLP: learns its own features
- Kernel SVM needs the support vectors at prediction time
