### What is a concept, and what is concept learning?
- A concept is a category, such as birds, spam emails or good days for a sport
- It can be seen as a yes or no function over the objects
- Concept learning: infer this function from labelled training examples
- Output is a boolean value: positive example or negative example

### The running example: EnjoySport
- Task: predict days on which Aldo enjoys his water sport
- Six attributes describe a day
- Target: Play is Yes or No
- We reuse this table in Part 4

### How do we write a hypothesis?
- A hypothesis has one constraint for each of the six attributes
- A constraint is a specific value, ? for any value, or ∅ for no value
- The hypothesis is the AND of all six constraints
- <Sunny, Warm, ?, Strong, ?, ?> : sunny AND warm AND strong wind

### Does a hypothesis cover a day? A tiny program
- Two extreme hypotheses: all question marks says every day is positive
- All empty set says no day is ever positive
- A hypothesis with even one ∅ can never be satisfied

```python
def covers(h, day):
    # h and day are lists of six values
    # "?" accepts any value; None is the empty set
    # and never equals a day's value
    return all(c == "?" or c == v
               for c, v in zip(h, day))
```

### Concept learning as search: counting
- Instances: 3 × 2 × 2 × 2 × 2 × 2 = 96 possible days
- Syntactically distinct hypotheses: 5 × 4 × 4 × 4 × 4 × 4 = 5120
- Each attribute: its values plus ? plus ∅
- Learning means searching this space for hypotheses that fit the examples

### Why only 973 semantically distinct hypotheses?
- Any hypothesis containing ∅ classifies every day as negative
- All of those behave the same, so count them as one
- Other hypotheses: 4 × 3 × 3 × 3 × 3 × 3 = 972
- Total: 972 + 1 = 973

### The general-to-specific ordering
- h1 is more general than or equal to h2 if every day h2 accepts, h1 also accepts
- More general means more question marks
- Only a partial order: some pairs cannot be compared

### The Find-S algorithm
- 1. Start with h = the most specific hypothesis, all ∅
- 2. For each positive example x, and for each attribute of h:
- If x satisfies the constraint, keep it. Otherwise replace it with the next more general constraint
- 3. Ignore every negative example
- 4. Output h

### Find-S in a few lines of code
- Written as a loop, the algorithm is short
- One pass over the data, no backtracking

```python
def find_s(examples):
    h = [None] * 6          # None = empty set
    for x, label in examples:
        if label != "Yes":
            continue        # ignore negatives
        for i, v in enumerate(x):
            if h[i] is None:
                h[i] = v    # first positive
            elif h[i] != v:
                h[i] = "?"  # generalise
    return h
```

### Find-S trace on EnjoySport
- After 1: the exact first day
- After 2: Humid becomes ?, after 3: unchanged
- After 4: Water, Fcast become ?

### Why the answer is correct
- Output is the most specific hypothesis that covers all positive examples
- The true concept also covers all positives, so it is at least as general as h
- So h cannot accept anything the true concept rejects, if the target is in our space
- Check: final h rejects example 3, the rainy cold day

### Limitations of Find-S
- Cannot tell if it found the only hypothesis consistent with the data
- Ignores negative examples completely
- Cannot detect noisy or inconsistent data
- There may be several maximally specific hypotheses; Find-S returns one

### Common mistakes to avoid
- Saying a hypothesis is a OR of conditions: it is an AND
- Changing the hypothesis on a negative example in Find-S
- Turning a ∅ straight into ? instead of the example's value
- Mixing up 96 instances, 5120 and 973 hypotheses
