- The perceptron is a neuron with learnable weights and a bias input fixed at -1; it fires (output 1) only if the activation a > 0.
- Learning rule: w_i = w_i + eta (t - y) x_i, so weights change only when the output is wrong.
- One epoch is one pass over all training examples; training stops when a whole pass has no errors.
- Trained on AND, the perceptron settles at w = (2, 2, 1) after 6 passes, with boundary 2 x1 + x2 = 2.
- The decision boundary is a line (a hyperplane in more dimensions); classes it can split are linearly separable.
- AND, OR and NOT are linearly separable; XOR is not, because no single line separates its two classes.
- Convergence theorem: for linearly separable data, the perceptron finds a perfect boundary in finitely many updates.
- Exam takeaway: XOR needs more than one layer of neurons, which leads to the multi-layer perceptron.
