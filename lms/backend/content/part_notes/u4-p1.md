- Too many features cause slow training, noise and empty space (curse of dimensionality); distances between points lose meaning.
- Feature selection keeps a subset of the original columns; feature extraction builds new features as weighted sums of all of them.
- LDA is supervised: it finds one direction `w` so that projected class means are far apart and each class stays tight.
- `S_W` is the within-class scatter and `S_B` the between-class scatter; the Fisher criterion is `J(w) = w^T S_B w / w^T S_W w`.
- For two classes the best direction is `w` proportional to `S_W^-1 (m1 - m0)`; only the direction matters, so scale `w` to length one.
- Worked example: means (2.5, 4.5) and (4.5, 1.5), `S_W` = [[11, 5], [5, 11]], `w` = (0.6522, -0.7580), J = 2.11.
- With C classes LDA gives at most C - 1 useful directions, and it fails when `S_W` cannot be inverted (more features than examples).
