- A hidden Markov model (HMM): hidden states follow a Markov chain and each state emits a visible observation. We see only the observations.
- An HMM is defined by the start probabilities pi, transition matrix A and emission matrix B; each row sums to 1.
- Three problems: evaluation (forward algorithm), decoding (Viterbi) and learning (Baum-Welch).
- Forward algorithm: alpha(t, j) = (sum over i of alpha(t-1, i) A(i, j)) x B(j, obs t). The last column added up gives the sequence likelihood.
- Forward is a sum over all hidden paths done efficiently; in the example it equals the brute-force total over 16 paths, 0.011189.
- Viterbi uses the same trellis but takes the maximum and stores backpointers; trace back from the best last state to get the best path.
- Baum-Welch is an EM method: forward-backward gives soft state probabilities (E step), then expected counts re-estimate A, B, pi (M step).
- Baum-Welch raises the log-likelihood every iteration but finds only a local optimum, so try several starts.
