### Recap of Part 5: the perceptron
- Weighted sum with bias input -1; fires if a > 0
- Learning rule: w_i = w_i + eta (t - y) x_i, only on mistakes
- Learned AND in 6 passes; cannot learn XOR
- Works only when the classes are linearly separable

### The regression problem
- Regression: predict a continuous target t from input x
- Linear model: y = b0 + b1 x (a plane or hyperplane for many inputs)
- b0 is the intercept, b1 is the slope
- Learning means choosing b0 and b1 so that y is close to t

### Our data set and the residuals
- x = 1, 2, 3, 4, 5 and t = 2, 4, 5, 4, 5
- A candidate line: y = 2.2 + 0.6x
- Residual = t - y: the vertical gap from point to line
- Residuals: -0.8, 0.6, 1.0, -0.6, -0.2

### Sum of squares error
- Error: E = sum of (t_i - y_i)^2
- Squares make every term positive: no cancelling
- Large misses are punished more than small ones

### Deriving the solution
- E = sum of (t - b0 - b1 x)^2 is a bowl shape in (b0, b1)
- At the bottom, both slopes are zero: dE/db0 = 0 and dE/db1 = 0
- n b0 + b1 (sum x) = sum t
- b0 (sum x) + b1 (sum x^2) = sum x t

### The closed-form formulas
- Slope: b1 = sum (x - xbar)(t - tbar) / sum (x - xbar)^2
- Intercept: b0 = tbar - b1 xbar
- xbar and tbar are the means of x and t
- The line always passes through the point (xbar, tbar)

### Worked example: the numbers from code
- xbar = 3, tbar = 4, sum (x - xbar)(t - tbar) = 6, sum (x - xbar)^2 = 10
- b1 = 6 / 10 = 0.6;  b0 = 4 - 0.6 x 3 = 2.2

```python
import numpy as np
x = np.array([1, 2, 3, 4, 5.0]); t = np.array([2, 4, 5, 4, 5.0])
xm, tm = x.mean(), t.mean()
sxt = ((x - xm) * (t - tm)).sum()
sxx = ((x - xm) ** 2).sum()
b1 = sxt / sxx
b0 = tm - b1 * xm
print(xm, tm, sxt, sxx)
print(round(b1, 2), round(b0, 2))
```

### Checking the fit and predicting
- Predictions at x = 1..5: 2.8, 3.4, 4.0, 4.6, 5.2
- Sum of residuals = 0; sum of squared residuals E = 2.4
- Total spread of t about its mean = 6, so the line explains 60%
- Prediction for x = 6: 2.2 + 0.6 x 6 = 5.8

### The normal equation in matrix form
- Add a column of ones to X; then b = (X^T X)^-1 X^T t
- X^T X = [[5, 15], [15, 55]],  X^T t = [20, 66]
- Solution: b = (2.2, 0.6), the same line
- Works for any number of inputs: one column per input

```python
X = np.column_stack([np.ones(5), x])
print(X.T @ X)
print(X.T @ t)
print(np.linalg.solve(X.T @ X, X.T @ t))
```

### Regression as a classifier
- Code the classes as targets 0 and 1, then fit the line
- Data: x = 1..6, targets 0, 0, 0, 1, 1, 1
- Fitted line: y = -0.4 + 0.257 x
- Rule: class 1 if y > 0.5; the boundary is x = 3.5

### Limitations: outliers and shape
- Add one far point (x = 20, class 1) and refit
- New line: y = 0.301 + 0.046 x; crossing moves to x = 4.31
- The point x = 4 gives 0.486, so it is misclassified

### Regression as a perceptron-like discriminant
- AND with targets 0, 0, 0, 1: least squares gives y = -0.25 + 0.5 x1 + 0.5 x2
- Outputs: 0.25, 0.25, 0.25, 0.75; threshold 0.5 gives AND
- XOR: least squares gives y = 0.5 for every input, so it fails too
- Regression: direct formula; perceptron: repeated updates

### Common mistakes
- Adding residuals instead of squared residuals
- Computing the slope with sum of x times t only, and forgetting the means
- Mixing up b0 and b1, or forgetting b0 = tbar - b1 xbar
- Extrapolating far outside the data range
