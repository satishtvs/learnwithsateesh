- One perceptron cannot do XOR; hidden nodes first build new features and then the output node separates them.
- An MLP has an input layer, one or more hidden layers and an output layer, fully connected and feed-forward.
- Forward pass: net input z = sum of weights times inputs plus bias, then activation a = g(z), layer by layer.
- Weights in an m-L-n network: (m+1)L + (L+1)n, counting biases.
- Activations: step, sigmoid 1/(1+e^-z) in (0,1), tanh in (-1,1) and ReLU max(0,z).
- Activations must be non-linear; with linear ones, stacked layers collapse into a single linear layer.
- Output choice: linear for regression, one sigmoid for two classes, softmax for many classes (positive, sum to 1).
- Exam takeaway: show an MLP solving XOR, with one hidden node detecting OR and another detecting AND.
- Worked 2-2-1 example (x = 1, 0, target 1): hidden activations 0.6225 and 0.5498, output 0.6007, error 0.0797.
