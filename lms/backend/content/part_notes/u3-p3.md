- Ensemble learning combines many models; it helps only when their errors are different (independent).
- Three independent voters, each 60% accurate, give a majority vote that is correct with probability 0.648.
- Bootstrap sample: draw N from N with replacement; about 63.2% of distinct items appear, the rest are out-of-bag.
- Bagging trains one deep tree per bootstrap sample and votes (or averages); it mainly reduces variance.
- Random forest = bagging plus a random subset of features at each split (about square root of d), so trees differ more.
- AdaBoost: error = weight of mistakes, `alpha = 0.5 ln((1-error)/error)`; mistakes get heavier weights for the next stump.
- Round 1 example: error 0.2 gives alpha 0.6931. Boosting is sequential and reduces bias; bagging is parallel.
- Other combiners: hard and soft voting, stacking (meta-learner), and mixture of experts (gate weights depend on x).
