- A decision tree asks one question per internal node, each branch is an answer, and each leaf gives a class.
- Entropy `H = -sum(p_i log2 p_i)` measures how mixed a node is: 0 for a pure node, 1 bit for a 50-50 split.
- Information gain = entropy before the split minus the weighted average entropy of the children.
- ID3 is greedy and recursive: at every node pick the feature with the highest gain, branch on its values, repeat.
- In the attendance example, "Exam soon" wins at the root with gain 0.35 (Weather 0.1258, Bus 0.0817).
- Every root-to-leaf path is an if-then rule, so a tree is easy to read and explain.
- Growing until every leaf is pure overfits; stop early or prune. Gain favours many-valued features, so C4.5 uses gain ratio.
- Exam takeaway: show counts per branch, the weighted entropy, then subtract; always use log base 2.
