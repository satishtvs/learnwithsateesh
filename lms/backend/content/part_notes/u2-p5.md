- Many lines separate the same data; an SVM picks the one with the widest empty margin, which is more robust to noise.
- Support vectors lie on the edges of the margin; only they determine the line, other points do not matter.
- Margin = 2 / length of w, so we minimise 1/2 |w|^2 subject to t_i (w.x_i + b) >= 1; convex, one global optimum.
- Dual form: w = sum of alpha_i t_i x_i, with alpha_i > 0 only for support vectors.
- Soft margin adds slack variables and minimises 1/2 |w|^2 + C sum of slack; small C gives a wide, tolerant margin.
- Kernel trick: K(x, z) = phi(x).phi(z) lets us separate non-linear data without ever computing phi.
- Common kernels: linear x.z, polynomial (1 + x.z)^d, Gaussian exp(-gamma |x - z|^2); a very large gamma overfits.
- Multi-class SVM uses one-versus-rest (K classifiers) or one-versus-one (K(K-1)/2); tune C and gamma by cross validation.
