- Designing a learning system has four steps in order: training experience, target function, representation, learning algorithm.
- Direct feedback gives the best move for each position; indirect feedback gives only the final result.
- Credit assignment problem: feedback comes at the end, so it is hard to tell which earlier moves were responsible.
- Checkers target function V(b) scores a board; it is a weighted sum of board features, w0 + w1x1 + ... + w6x6.
- LMS rule: w_i = w_i + eta (V_train(b) - V(b)) x_i, so weights move in proportion to the error.
- Worked example: V(b) = 5, V_train(b) = 6, eta = 0.01 gives error 1, each weight rises by 0.01 x its feature, and the new score is 5.41.
- Eta must be small; a large learning rate makes the error swing wider instead of shrinking.
- Learning is a search through a hypothesis space; overfitting means fitting noise and failing on new data.
- Exam takeaway: write the four design steps with the checkers example and compute one LMS update.
