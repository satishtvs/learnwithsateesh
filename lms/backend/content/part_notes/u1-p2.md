### Recap of Part 1
- Learning: improve at task T, measured by P, with experience E
- Types: supervised, unsupervised, reinforcement, evolutionary
- Supervised: classification and regression
- Judge a model on test data: generalisation
- Neuron: weighted sum compared with a threshold

### Designing a learning system: the checkers example
- T: play checkers
- P: percent of games won
- E: games played against itself
- Four steps, always in this order

### Step 1: Choosing the training experience
- Direct feedback: the best move for every board position
- Indirect feedback: only the final result, win or loss
- Direct is easier to learn from, but harder to obtain
- Training data should resemble the situations met later

### The credit assignment problem
- A game has many moves, but feedback comes only at the end
- Which moves caused the loss?
- Needs many games to sort out

### Step 2: Choosing the target function
- Target function V(b): a score for every board b
- Higher score means a better board for us
- Best move: the one leading to the highest-scoring board
- Winning board: high score; losing board: low score

### Step 3: Choosing the representation
- V(b) = w0 + w1x1 + w2x2 + ... + w6x6
- x1, x2: black and red pieces; x3, x4: black and red kings
- x5, x6: black and red pieces under threat
- Learning means finding good weights w0 to w6
- Richer form: more power, but needs more data

### Step 4: The learning algorithm
- Training value: V_train(b) = V(next board for us)
- LMS rule: w_i ← w_i + η (V_train(b) − V(b)) x_i
- η is the learning rate, a small positive number
- Error positive: weights on active features go up

### Worked example: one LMS update
- x0 = 1 for the constant weight w0
- V(b) = 5.0, V_train = 6.0, error = 1.0

```python
x = [1, 5, 3, 1, 0, 1, 2]
w = [0.5, 1.0, -1.0, 2.0, -2.0, -0.5, 0.5]
eta, v_train = 0.01, 6.0
v = sum(a * b for a, b in zip(w, x))
print(v)                       # 5.0
w = [a + eta * (v_train - v) * b for a, b in zip(w, x)]
print([round(a, 2) for a in w])
print(sum(a * b for a, b in zip(w, x)))
```

### Why the learning rate must be small
- Repeat the update on the same board
- Eta 0.01: error shrinks by 0.59 each step
- Eta 0.1: error swings wider and wider

### Perspectives: learning as search
- Hypothesis space: all functions the representation can express
- Learning = searching it for the hypothesis that best fits the data
- Checkers: every choice of seven weights is one hypothesis
- Representation decides how big the space is

### Issues in machine learning
- How much training data is enough?
- Which algorithm for which kind of data?
- Can prior knowledge help the learner?
- Which training example should the learner ask for next?
- Can the learner change its own representation?

### Overfitting
- Overfitting: fitting the noise, not the pattern
- Excellent on training data, poor on new data
- Too flexible a model or too little data
- Remedies: more data, simpler model, validation set
