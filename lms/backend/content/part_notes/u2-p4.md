- A sigmoid unit responds over half the input space; a Gaussian unit responds only near its centre (a local receptive field).
- RBF response depends on distance from a centre: phi = exp(-distance^2 / (2 sigma^2)), with width sigma.
- RBF network: input layer, one Gaussian hidden unit per centre, and a linear output y = sum of w_m phi_m(x) plus bias.
- Training an RBF: choose centres (k-means), choose widths, then solve the output weights by least squares; no back-propagation.
- MLP hidden units are global sigmoids trained by gradient descent; RBF training is faster and repeatable.
- Curse of dimensionality: data becomes sparse as dimensions grow; a cube holding 10 percent of data needs edge near 0.98 at d = 100.
- Remedies for high dimensions: fewer inputs, feature selection, or more structure in the model.
- Splines are piecewise polynomials joined at knots; cubic splines are smooth and fit better than linear ones with the same knots.
- Worked example: 8 Gaussian units (k-means centres, sigma 0.21) fit x sin(2 pi x) with test RMSE 0.057, close to the noise level 0.05.
