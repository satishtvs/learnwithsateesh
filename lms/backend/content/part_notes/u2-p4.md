### Local versus global response
- Sigmoid unit: responds on a whole half of the input space
- Gaussian unit: responds only near its centre
- Local response is called a receptive field

### Radial basis functions
- Response depends only on distance from a centre
- Gaussian: phi = exp(-(distance squared) / (2 sigma squared))
- Centre c: where the response is highest (equal to 1)
- Width sigma: how far the receptive field reaches

### The RBF network architecture
- Input layer: just passes x on
- Hidden layer: one Gaussian unit per centre
- Output layer: linear, weighted sum of hidden outputs
- y = w1 phi1(x) + w2 phi2(x) + ... + wM phiM(x) + bias

### How an RBF network is trained
- Step 1: choose the centres (k-means, or pick data points)
- Step 2: choose the widths (for example from centre spacing)
- Step 3: solve the output weights by least squares
- No back-propagation through the hidden layer

### Training an RBF versus an MLP
- RBF: unsupervised centres, then one linear solve
- MLP: all weights learned together by gradient descent
- RBF training is fast and repeatable
- MLP can learn where to put its features, using the targets

### Worked example: fitting a function with an RBF network
- f(x) = x sin(2 pi x), noise 0.05
- 40 training, 500 test points

```python
C = kmeans(X, 8)
sigma = dmax / np.sqrt(2 * 8)
Phi = np.exp(-d2 / (2 * sigma**2))
Phi = np.hstack([Phi, ones])
w = lstsq(Phi, t, rcond=None)[0]
```

### How many centres, and how wide?
- Too narrow: bumps do not overlap, poor fit
- Very wide: fits, but weights become huge
- Choose centres and width on a validation set

### RBF network versus MLP
- Hidden units: local Gaussians versus global sigmoids
- Training: k-means plus least squares versus back-propagation
- Same data: RBF test RMSE 0.057, MLP 0.063
- RBF needs many units in high dimensions
- Far from the data: RBF output falls to the bias

### The curse of dimensionality
- Data uniform in the unit cube
- To hold 10 percent of data, a cube needs edge 0.1^(1/d)
- d = 1: 0.10, d = 2: 0.32, d = 10: 0.79, d = 100: 0.98

### Consequences of the curse
- 10 bins per axis gives 10 to the power d cells
- d = 10: ten billion cells; d = 100: 10 to the power 100
- Ratio nearest to average distance: d = 2: 0.10, d = 100: 0.86
- Fix: fewer inputs, feature selection, more structure

### Interpolation and basis functions
- Interpolation: pass exactly through every data point
- Basis expansion: f(x) = sum of weights times basis functions
- Exact RBF interpolation: one centre per data point, solve Phi w = t
- With noisy data this overfits badly

### Splines: piecewise polynomials
- Linear spline: straight lines, corners at knots
- Cubic spline: smooth, continuous slope and curvature
- 6 knots: max error linear 0.149, cubic 0.042
