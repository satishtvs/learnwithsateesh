### What is learning?
- Learning: getting better at a task through experience
- A child sees a few cats and then recognises new cats
- Nobody gives the child a list of rules
- Machine learning: the computer finds the rules from examples

### Why not just write the rules?
- Some rules are too many or too hard to write down
- Spam: spammers change their tricks every week
- Speech, faces, medical images: we cannot describe how we do it
- Learned programs adapt when the data changes

### A formal definition: task, performance, experience
- A program learns from experience E on task T, with performance measure P,
- if its performance on T, as measured by P, improves with E
- Spam filter: T = classify email, P = percent classified correctly, E = emails labelled by users
- Handwriting: T = read a digit, P = percent correct, E = images with the true digit

### Types of machine learning
- Supervised: examples come with correct answers
- Unsupervised: no answers; find groups or structure
- Reinforcement: trial and error with rewards
- Evolutionary: improve a population by selection

### Supervised learning
- Training set: inputs x with their targets t
- Goal: a function that predicts t for new inputs
- Examples: house features to price, image to cat or dog
- The teacher is the set of known answers in the data

### Classification and regression
- Classification: the target is a class
- Regression: the target is a number on a continuous scale
- Classification draws a boundary
- Regression fits a curve

### Training, testing and generalisation
- Training set: used to learn
- Test set: kept aside to measure performance
- Memorising the training set is not learning

### Validation sets and common mistakes
- Validation set: used to tune settings and decide when to stop
- Never tune the model on the test set
- Training accuracy alone says little
- Typical split: about 60 percent train, 20 validation, 20 test

### The brain and the neuron
- About 100 billion neurons, each connected to thousands of others
- Dendrites receive signals and the cell body adds them up
- If the total is large enough, the neuron fires along its axon
- Learning changes the strength of the connections, the synapses

### The McCulloch and Pitts neuron
- Multiply each input by its weight and add
- Sum above threshold: output 1, otherwise 0
- Weights play the role of synapse strengths

### A neuron in code: the AND gate
- Weights 1 and 1, threshold 1.5
- Fires only when both inputs are 1

```python
def neuron(x, w, threshold):
    total = sum(a * b for a, b in zip(x, w))
    return 1 if total > threshold else 0

for a in (0, 1):
    for b in (0, 1):
        print(a, b, neuron([a, b], [1, 1], 1.5))
```

### Hebb's idea: neurons that fire together
- Donald Hebb, 1949
- Connections between neurons that fire together get stronger
- In a model: increase the weight when both input and output are active
- Learning = changing weights
