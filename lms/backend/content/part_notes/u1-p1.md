- Learning means improving at a task T, measured by performance P, with experience E (Mitchell). Spam filter: E is user-labelled emails.
- Four types: supervised (answers given), unsupervised (find groups), reinforcement (rewards), evolutionary (selection).
- Supervised learning splits into classification (target is a class) and regression (target is a number).
- Use separate training, validation and test sets; memorising the training set is not learning, generalisation is.
- Never tune the model on the test set; validation data is for choosing settings and when to stop.
- McCulloch and Pitts neuron: weighted sum of inputs, output 1 if the sum is above a threshold, else 0. Example: inputs 1, 0, 1 with weights 0.5, -0.3, 0.8 give 1.3, above threshold 1, so it fires.
- Hebb's rule: connections between neurons that fire together get stronger, so learning means changing weights.
