- Training set changes the weights, validation set decides when to stop and compares settings, test set is used once at the end.
- Overfitting: training error keeps falling but validation error starts rising; early stopping keeps the best weights.
- Learning rate: too small is very slow, too large makes the error blow up; tune it on the validation set.
- Momentum adds part of the previous weight change, smoothing zig-zags and speeding progress along valleys.
- Too few hidden nodes underfit, and a very large network overfits unless you stop early; choose their number by validation error.
- Gradient descent can get stuck in local minima, so restart from several random weight sets.
- Scale inputs (subtract the training mean, divide by the training standard deviation) so no input dominates.
- Regression uses a linear output, classification uses one-of-N targets with softmax; one hidden layer can approximate any continuous function.
- Worked results: the sine regression reached test RMSE 0.11 (noise 0.10), and the three-class problem reached 91.3 percent test accuracy.
