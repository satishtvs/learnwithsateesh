### Recap of Part 2: back-propagation
- Forward pass: inputs flow through hidden layer to outputs
- Error compares outputs y with targets t
- Backward pass: output deltas, then hidden deltas
- Update each weight by eta times delta times its input

### Training, validation and test sets
- Training set: used to change the weights
- Validation set: used to decide when to stop and to compare settings
- Test set: used once at the end for an honest estimate
- Typical split: about 50 percent, 25 percent, 25 percent

### Overfitting and early stopping
- Training error keeps falling
- Validation error falls, then rises
- Stop at the lowest validation error; keep the best weights

### Learning rate
- Too small: very slow progress
- Too large: error explodes
- Typical eta between 0.01 and 0.5
- Try a few values on the validation set

### Momentum
- Remember part of the previous weight change
- Smooths zig-zags, speeds up along valleys
- Momentum is usually around 0.9

```python
# one weight update with momentum
v = momentum * v - eta * gradient
w = w + v
# momentum = 0 gives plain gradient descent
```

### How many hidden layers and nodes?
- One hidden layer is enough to start
- Too few nodes: underfitting
- Too many nodes: overfitting risk
- Choose by validation error

### Local minima and random restarts
- Error surface has many valleys
- Gradient descent can get stuck in a poor one
- Start from several random weight sets
- XOR, 2 hidden nodes: 17 of 20 starts solved
- XOR, 4 hidden nodes: 20 of 20 solved

### Scale the inputs
- Put every input on a similar scale
- Standardise: subtract mean, divide by standard deviation
- Use training-set mean and deviation on all sets
- Test: raw inputs 53.5 percent, scaled 100 percent

### Amount of data and batch versus sequential
- More weights need more examples
- Few examples: smaller network, early stopping
- Batch: one update per pass over all data
- Sequential: one update per example, shuffled each epoch

### Example one: regression, fitting a sine
- Data: 40 train, 20 validation, 500 test points
- Network: 1 input, 6 sigmoid hidden, 1 linear output; eta 0.3, momentum 0.9
- Early stopping: test RMSE 0.11, noise level 0.10

### Example two: classification with one-of-N outputs
- 3 classes, targets (1,0,0), (0,1,0), (0,0,1)
- 2 inputs, 5 hidden, 3 softmax outputs
- Stopped at epoch 60 by validation error
- Test accuracy 91.3 percent (274 of 300)

### Time series and universal approximation
- Time series: inputs are the last few values, target is the next value
- Split by time, never shuffle validation or test data into the past
- Universal approximation: one hidden layer can approximate any continuous function
- It says a good network exists, not that training will find it

### Overview of the multi-layer perceptron
- Layers of weighted sums plus nonlinear activations
- Trained by back-propagation, a form of gradient descent
- Linear output for regression, softmax for classes
- Needs scaled inputs, three data sets, early stopping
- Weaknesses: local minima, slow training, many settings to tune
