- Linear methods squash curved data; a manifold is a surface that looks flat when you zoom in (for example the swiss roll).
- Isomap replaces straight-line distance with geodesic distance, the shortest path along the surface.
- Isomap steps: k-nearest-neighbour graph, shortest paths between all pairs, then multidimensional scaling (MDS).
- A small k breaks the graph into pieces; a large k creates short circuits across layers, so choose k carefully.
- LLE rebuilds each point from its neighbours with weights that sum to one, then finds low-dimensional points using the same weights.
- LLE solves for the smallest eigenvectors of `(I - W)^T (I - W)`, skipping the constant one; it never computes long distances.
- Least squares minimises the sum of squared errors; for a linear model the normal equation is `X^T X beta = X^T y`.
- For curved models there is no closed form: Gauss-Newton linearises each step, and Levenberg-Marquardt adds `lambda I` as damping.
