### Recap of Part 1
- MLP: input, hidden and output layers, fully connected
- Forward: z = V x + b, a = g(z); u = w a + b, y = g(u)
- Example: x = (1, 0), target 1, output y = 0.6007
- Sigmoid g(z) = 1/(1 + e^-z) at every node

### The error function
- E = 1/2 * sum over outputs k of (t_k - y_k)^2
- E depends on all the weights through y
- Goal: walk downhill on the error surface to small E

### Gradient descent in weight space
- Gradient of E points uphill; move the opposite way
- Update: w = w - eta * (dE/dw)
- eta is the learning rate: step size
- Too big: overshoots. Too small: very slow
- Convention here: delta = dE / d(net input)

### The delta rule, and the hidden-node problem
- Unit I: w = w - eta (y - t) x works for one layer
- For an output node we know its target, so its error is known
- For a hidden node there is no target
- Credit assignment: how much did this hidden node contribute?
- Answer: pass the output errors back along the weights

### The picture: errors flow backwards
- Forward: inputs to outputs, compute y
- Backward: delta at the output first, then at each hidden node
- Then every weight is updated; numbers are for our 2-2-1 example

### Derivation 1: the output weights
- u_k = sum_j w(k,j) a_j + b_k;  y_k = g(u_k)
- dE/dw(k,j) = (dE/du_k) * (du_k/dw(k,j))
- du_k/dw(k,j) = a_j
- dE/du_k = (dE/dy_k)(dy_k/du_k) = -(t_k - y_k) g'(u_k)
- So delta_k = (y_k - t_k) g'(u_k)

### The sigmoid has a lovely derivative
- g(z) = 1/(1 + e^-z)
- g'(z) = e^-z / (1 + e^-z)^2 = g(z) (1 - g(z))
- In terms of the activation: g' = a (1 - a)
- Never more than 0.25; tiny when a is near 0 or 1

### Result for the output layer
- delta_k = (y_k - t_k) y_k (1 - y_k)   (sigmoid output)
- delta_k = (y_k - t_k)   (linear output, regression)
- Gradient: dE/dw(k,j) = delta_k a_j
- Update: w(k,j) = w(k,j) - eta delta_k a_j
- Bias: b_k = b_k - eta delta_k

### Derivation 2: the hidden weights
- z_j = sum_i v(j,i) x_i + b_j;  a_j = g(z_j)
- v(j,i) changes z_j, then a_j, then every u_k
- dE/dv(j,i) = (dE/dz_j) x_i = delta_j x_i
- delta_j = g'(z_j) * sum_k w(k,j) delta_k
- For sigmoid: delta_j = a_j (1 - a_j) sum_k w(k,j) delta_k

### The back-propagation update rules
- Output: delta_k = (y_k - t_k) y_k (1 - y_k)
- Hidden: delta_j = a_j (1 - a_j) sum_k w(k,j) delta_k
- w(k,j) = w(k,j) - eta delta_k a_j
- v(j,i) = v(j,i) - eta delta_j x_i
- Biases: same, with the input taken as 1

### The complete algorithm
- 1. Initialise all weights to small random numbers
- 2. Forward pass: compute activations and outputs
- 3. Output deltas, then hidden deltas going backwards
- 4. Update every weight and bias
- 5. Repeat over the training set until the error is small

### Batch versus sequential updating
- Sequential (online): update after every example
- Batch: add up the gradients over all examples, update once
- Sequential is noisy but often faster, shuffle the order
- Batch follows the true gradient of the total error
- Both are called back-propagation

### Worked example: the deltas
- Forward (Part 1): a = (0.6225, 0.5498), y = 0.6007, t = 1, eta = 0.5
- delta_o = (0.6007 - 1)(0.6007)(0.3993) = -0.0958
- delta_h1 = 0.6225(0.3775)(0.6)(-0.0958) = -0.0135
- delta_h2 = 0.5498(0.4502)(-0.3)(-0.0958) = +0.0071

### Worked example: the updates
- w(o,h1): 0.6 - 0.5(-0.0958)(0.6225) = 0.6298
- w(o,h2): -0.3 - 0.5(-0.0958)(0.5498) = -0.2737;  b_o = 0.2479
- v(h1,x1) = 0.4068, b_h1 = 0.1068;  v(h2,x1) = 0.2964, b_h2 = -0.1036
- v(h1,x2), v(h2,x2) unchanged, since x2 = 0
- New forward pass: y = 0.6206; E: 0.0797 down to 0.0720
