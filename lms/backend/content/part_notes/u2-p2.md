- Error function: E = 1/2 times the sum over outputs of (t_k - y_k)^2, minimised by gradient descent.
- Gradient descent update: w = w - eta times dE/dw; a large eta overshoots and a small one is very slow.
- A hidden node has no target of its own, so output errors are passed back along the weights (credit assignment).
- Sigmoid derivative: g'(z) = g(z)(1 - g(z)), never more than 0.25.
- Output delta (sigmoid): delta_k = (y_k - t_k) y_k (1 - y_k); for a linear output it is just (y_k - t_k).
- Hidden delta: delta_j = a_j (1 - a_j) times the sum over k of w(k,j) delta_k.
- Each update is weight = weight - eta times delta times the value feeding that weight; biases use input 1.
- Sequential updates after each example (shuffle the order); batch adds gradients over all examples, then updates once.
- Worked step (eta = 0.5): output delta -0.0958, hidden deltas -0.0135 and +0.0071; the output moves from 0.6007 to 0.6206 and the error drops from 0.0797 to 0.0720.
