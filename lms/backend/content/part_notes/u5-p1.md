- Reinforcement learning (RL): no correct answers are given; the agent tries actions and learns from a reward, a single number.
- Loop: the agent observes a state, takes an action, and the environment returns a reward and a new state. The agent controls only its actions.
- A policy is a rule that picks an action in each state; it can be deterministic or stochastic. RL aims to find a good policy.
- Return G = r1 + gamma r2 + gamma^2 r3 + ..., with discount factor gamma between 0 and 1; small gamma is short-sighted.
- Getting Lost grid (5 x 5): reward -1 per cell, -5 for a pond, +20 at the goal. The 8-move route has return 4.3489 at gamma = 0.9.
- Exploit means using the best known action; explore means trying others. Epsilon-greedy explores with probability epsilon; pure greedy can get stuck.
- RL vs supervised learning: only a reward (no labels), delayed reward (credit assignment), data depends on the policy, and the agent must explore.
- Exam takeaway: draw the agent-environment loop, define return and gamma, and be ready to compute a discounted return.
