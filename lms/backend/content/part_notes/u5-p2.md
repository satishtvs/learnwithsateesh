- A Markov decision process (MDP) has states, actions, rewards, discount gamma and transition probabilities P(s' | s, a).
- Markov property: the next state and reward depend only on the current state and action, not on the earlier history.
- V(s) is the expected return from state s under a policy; Q(s, a) is the expected return if you take action a first, then follow the policy.
- Bellman equation: value = reward now + gamma x value of the next state. Optimal: V*(s) = max over a of (r + gamma V*(s')).
- Value iteration sweeps the grid with the Bellman rule until nothing changes; it needs the model. Start cell reaches 4.3489.
- Q-learning update: Q(s,a) = Q(s,a) + alpha x (target - Q(s,a)), where target = r + gamma x best Q of the next state.
- Sarsa uses the Q of the next action actually taken. Q-learning is off-policy; Sarsa is on-policy.
